# PersonaAI 前端设计规范（Agent 必读）

> 所有改 UI 的 agent 在动手前先读完这份。Token 数值以 [src/theme/tokens.css](../src/theme/tokens.css) 为准；本文件讲的是**结构与行为约定**。产出主题：Hallmark **Hum**。

## 0. Hum 风格铁则（每次改动都要自检）

- 只用 [tokens.css](../src/theme/tokens.css) 既有颜色/圆角/阴影/纹理 token，**不新增颜色或字体**；新组件从既有类组合（`.card`/`.btn`/`.knob`/`.chip`），不自造变体。
- 纸面三件套不可省：`var(--grain), var(--fibre), 底色`。阴影走 token（`--shadow-card`/`--shadow-paper`），光从左上、影往右下。
- 按钮必须有 `--edge` 压下物理（hover 边变厚、active 压到底）；圆角用 `--radius-card`(24px)/`--radius-stock`(16px)，不发明新数值。
- 标题用 `--font-display` 600、`--tracking-display`；正文 `line-height ≥ 1.4`。
- 任何容器（卡片、条带、弹窗）内的文字与边缘至少 24px 安全距；标题不贴边。
- 出卡片前先问：它和已有 `.card` 的差别是什么？差别不够就不用新类。

## 1. 全站统一顶栏（每页都有，不例外）

- **结构**：`src/components/ui/NavBar.tsx` 渲染一个 `<header class="topbar">`，挂在 `AppShell`，所有路由（含 `/landing`、登录页）共用。**页面自己不得再画顶栏**。
- **内容（左→右）**：
  1. `PersonaAI` wordmark → 链到 `/landing`
  2. 桌机（≥64rem）nav knobs：AI 朋友 / 大厅 / 历史
  3. 右端：已登录 → 阿澈钮（通知）+ **Profile 钮**（头像圆片+昵称 → `/profile`）；未登录 → **开始使用**（梨黄 primary 小按钮 → `/`）
- **行为**：
  - `position: sticky; top: 0`，滚动时贴顶；滚过 8px 后 `app-shell.is-scrolled` 会让阴影加深（阴影是 `filter: drop-shadow`，因为 `clip-path` 会裁掉 `box-shadow`）。
  - 手机（<64rem）：`.knobs` 隐藏，nav 收进底部 `.tabbar`（朋友/大厅/历史/我的档案 4 格，卡纸风、贴底、safe-area）；顶栏仍显示 wordmark + 右端钮。
- **禁止**：新增页面时另起顶栏、把 topbar 改成非 sticky、用 `box-shadow` 替代 drop-shadow（会被撕纸 clip-path 裁掉）。

## 2. 短页垂直居中

- 内容不足一屏的页面（目前：登录 `/`）在 `AppShell` 的 `CENTER_PAGES` 数组里登记，`app-main` 会拿到 `.page-center`（`place-content: center`）。
- 页面组件**不要自己写 `min-height: 100svh`**——居中是外壳的职责。
- 落地页是长滚动页，**不**进 `CENTER_PAGES`。

## 3. 布局骨架

- **宽度（桌机 ≥64rem）**：一般页 `--container: min(100vw - 80px, 1600px)` 近全窗展开；信息页（landing）用 `--container-wide: min(100vw - 80px, 1760px)`。手机一律全宽＋gutter。
- **双栏页**（桌机）：AI 朋友（`.friend-layout` 聊天 1.6fr＋侧栏 1fr）、我的档案（`.profile-layout` 档案 1.5fr＋记忆 1fr）、设置（`.profile-layout`）。手机单栏。新页面内容多时照这个模式开双栏，`grid-template-columns` 一律 `minmax(0, Nfr)`。
- `.app-shell`（flex column, `overflow-x: clip`）→ `.topbar`（sticky）→ `.app-main` → `.tabbar`（fixed 底）。
- **卡片内距**：`.card` 统一 `padding: var(--space-lg)`（24px）——内容绝不贴容器边缘。特例显式归零（如 `.friend-chat` 聊天卡：分区排版，内距写在分区上）。
- 卡片：`.card`（grain+fibre 纸面、`box-sizing: border-box`、`min-width: 0`、`overflow-wrap: anywhere`）。grid 子项一律 `minmax(0, 1fr)`，防溢出。
- 文案栏宽：标题 `max-width` 用 `ch` 单位（hero ≤14ch），不要满行。

## 4. 按钮/交互

- 主按钮 = `.btn--primary`（梨黄、54px、`--edge` 压下物理）；顶栏 CTA 用 `btn--small`。新按钮一律走 [Button.tsx](../src/components/ui/Button.tsx) 组件，不要手写 `<button className="btn">` 变体。
- 顶栏 nav 用 `.knob`（44px、`--edge: 3px`）；当前页 `.is-on`（墨色反白）。
- Profile 钮头像：`.knob__avatar` 圆片 28px、薄荷底、昵称首字。

## 5. Rive 资源

- 唯一入口 `src/components/ui/RiveAvatar.tsx` 的 `SOURCES`（语义键 → `public/riv/<file>.riv`）。目前：`robot: clover_bot.riv`、`fish: fish_vase.riv`、`birdie: red_birdie.riv`。
- 所有 `.riv` 内部 state machine 名称必须是 `State Machine 1`（新档若不同，改 SOURCES 旁的 `stateMachines` 常量，不要散落各页面）。
- 页面只引用语义键（`robot`/`fish`/`birdie`），**不直接写文件路径**。

## 6. 文案与 i18n

- 单语 zh-CN：所有 UI 文字走 [messages/strings.json](../messages/strings.json) + `t()`，不要在组件里硬编长句（顶栏少量短标签除外，已存在的照旧）。

## 7. 验证口径（快速迭代）

- 日常 checkpoint：`npx tsc -b`（约 2s）。
- 视觉改版任务：加一次目标页面截图；push 前一次 `npm test`。
- 不重复全页面宽度矩阵，除非导航/布局骨架被改动（那时才需要 375/768/1280 三档抽测）。
