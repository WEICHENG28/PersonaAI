## 二、依評分維度說明

### 創意與創新性（任務設計、工作流程、互動方式）
- **一句話交辦任務**：對 AI 朋友或大廳 AI 助手說「幫我找 3 個喜歡登山的人聊聊」，社交 Agent 解析成結構化任務，先複述給你確認再執行。
- **完成條件**：找到 N 位合適就停、今天最多代聊 N 場、期限，讓 Agent 知道何時算完成。
- **找人目的**：Agent 依目的調整挑人條件、開場話題和判定權重。

### 作品完成度（任務執行、流程完整、運行穩定）
- **異常處理**：

  | 狀況 | 處理 |
  |------|------|
  | 模型逾時、格式錯誤 | 自動重試 |
  | 工具呼叫失敗 | 重試一次，仍失敗就換下一位 |
  | 對方離線 | 改成稍後聊 |
  | 判定不確定 | 多聊幾輪再判定 |
  | 達到上限或完成條件 | 停止任務，由 AI 朋友回報 |

- **判定共識**：同一段對話判定 3 次取多數，不一致就延長對話。

### AI 技術應用（模型調用、任務規劃、自動化）
- **Agent 工作循環**：目標 → 規劃 → 執行 → 評估 → 決策 → 回報 →（未達完成條件就回到規劃）。
- **工作日誌附理由**：每一步都寫出「做了什麼」和「為什麼」；做成開發者開關，一般用戶預設看不到，Demo 時打開。
- **MVP 判定**：評審 Agent 依指標打 1–5 分 → 方向分數 = 平均 × 20 → 3 次取共識 → 單向合適看我的分數 ≥ 70，雙向合適看兩邊都 ≥ 70。

### 應用價值與潛力（任務效率提升、實際應用價值）
- **效率統計附計算依據**：
  > 「代聊 6 場 × 人工平均 20 分鐘 = 幫你省下約 2 小時。」（人工平均時間可調整）
- **找人目的延伸**：同一套 Agent 流程也能找讀書夥伴、運動夥伴、興趣同好。
